Stock Portfolio Tracker 📈

A Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

📌 Project Overview

The Stock Portfolio Tracker is a beginner-friendly Python project that uses sample stock prices in Indian Rupees (INR). It helps users work with stock information and manage portfolio entries through a simple console-based program.

✨ Features

- Displays available stocks and their sample prices.
- Accepts user input to add stock entries.
- Uses Python dictionaries to store stock prices.
- Uses lists to maintain portfolio data.
- Performs investment-related calculations.
- Provides a simple, interactive command-line interface.

🛠️ Technologies Used

- Python 3
- Visual Studio Code
- Git and GitHub

🚀 How to Run the Project

1. Install Python 3 on your computer.
2. Clone this repository or download the project files.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

 stock_tracker.py

6. Follow the instructions displayed in the terminal.

📚 Python Concepts Used

- Variables and data types
- Dictionaries and lists
- Loops
- Conditional statements
- User input and output
- Exception handling
- Basic calculations
