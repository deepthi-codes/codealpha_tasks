🎮 CodeAlpha Hangman Game

📌 About the Project

Hangman Game is a simple word-guessing game developed using Python as part of my CodeAlpha Python Internship.

The player must guess a hidden word one letter at a time within a limited number of attempts.

✨ Features

- Random word selection
- Hidden word displayed using blanks
- Guess one letter at a time
- Limited attempts to guess the word
- Input validation
- Messages for correct and incorrect guesses
- Win and lose messages

🛠️ Technologies Used

- Python
- Visual Studio Code
- GitHub

▶️ How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open "hangman_game.py".
5. Run the Python file.
6. Enter one letter at a time in the terminal to guess the hidden word.
